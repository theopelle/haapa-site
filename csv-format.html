The CSV format

Haapa exports every set you log as a plain CSV file that opens in Excel, Numbers, or Google Sheets. Here is what's inside, so your data is always yours to use.

The file

  • One row per set.
  • UTF-8 with a byte-order mark, so Excel shows ä, ö, å, and é correctly.
  • Comma-separated, with quotes only where a cell needs them.
  • Weights are always in kilograms with a dot decimal (82.5), whatever your phone's language.

The columns

ColumnExampleNotes
date2026-11-10The day the workout started.
workout_nameUpper A
start_time2026-11-10T18:02:00+02:00ISO 8601, with the time zone.
workout_duration_s3720Seconds. Empty if the workout was never finished.
exercise_nameBench Press (Barbell)In the app's language at the time of export.
set_order1Counts from 1 for each exercise.
set_typenormalnormal or warmup.
weight_kg82.5A negative number means assisted (bodyweight sets). Empty if none.
reps8Empty for timed sets.
duration_s60Timed sets only.
workout_notesRepeated on every row of the workout.
exercise_notesRepeated on every row of the exercise.
superset_groupAExercises with the same letter in one workout are a superset.
workout_id, exercise_id, set_id(ids)Stable ids, so importing the same file again never makes duplicates.

The first 11 columns are the ones people read. The ids at the end make it safe to import the file back into Haapa.

Importing

  • Haapa reads its own files, with the columns in any order.
  • It also reads exports from Strong and Hevy, and a simple spreadsheet layout for people coming from Excel or Google Sheets.
  • Semicolon and tab files work too, and so do decimal commas (82,5).
  • Weights in pounds are converted to kilograms.
  • Before anything is saved, you see a preview and can fix exercise names that don't match.
